# 报告详情卡牌并排预览设计

## 目标

在报告详情页直接展示当前报告生成的分享卡牌，让用户不必返回列表寻找“生成卡牌”入口。报告仍是主内容，卡牌是与这份报告绑定的可分享结果。

## 页面结构

桌面端采用双栏布局：

```text
┌──────── 固定高度报告 ────────┐   ┌──── 3:4 卡牌预览 ────┐
│ 返回报告列表                 │   │ 当前默认背景          │
│ 报告标题与各分析区块         │   │ 报告生成的文案        │
│ 内容超出时在框内滚动         │   │ 点击进入卡牌编辑页    │
└─────────────────────────────┘   └──────────────────────┘
```

- 左侧报告继续使用现有固定尺寸与内部滚动规则，不改变报告内容结构。
- 右侧显示现有 3:4 卡牌组件的缩放预览，默认使用“新艺术晨光”背景。
- 卡牌预览整体是一个明确可点击的按钮，点击进入现有卡牌页；背景切换、下载仍只在卡牌页完成，避免详情页出现重复控件。
- 桌面双栏整体居中，卡牌预览不新增第二个大型白色外框。

手机端保持单栏：报告内容之后显示卡牌预览入口。它属于报告滚动内容，因此不会改变系统统一的固定外框尺寸。

## 数据与状态

- 复用现有 `createShareCardContent`、`shareCardThemes`、`cardTheme` 和 `openCards`。
- 详情页的 `report` 在现有流程中均为已归档报告，可直接生成卡牌内容。
- 不存储第二份卡牌数据，不新增 API，也不改变报告归档格式。
- 从详情页进入卡牌页时继续传递当前报告；返回操作仍回到报告列表，与现有导航保持一致。

## 视觉与交互

- 卡牌内容、配色、背景图与“我的卡牌”页面完全一致，避免预览与下载结果不符。
- 右侧预览宽度约 300–340px，保持 3:4 比例；报告外框仍维持 560px 宽和统一固定高度。
- 预览提供可见的 hover、focus 状态和“查看并下载”提示，不依赖只有鼠标才能发现的交互。
- 不新增动画；仅沿用现有快速状态反馈，避免干扰报告阅读。

## 响应式规则

- `>= 960px`：报告与卡牌并排。
- `< 960px`：恢复单栏，卡牌入口放入报告内容末尾并随报告内部滚动。
- 两种布局都不能撑大报告外框；报告内容超出时继续在框内滚动。

## 错误与边界

- 若报告数据缺失，不渲染卡牌预览，保持现有报告兜底行为。
- 背景图片加载失败时仍保留卡牌底色和文字，不阻断报告阅读。
- 长标题、共情文案和关键词继续使用现有卡牌截断与排版规则。

## 验收标准

1. 桌面报告详情右侧显示与当前报告一致的 3:4 卡牌。
2. 点击右侧卡牌能进入对应报告的卡牌页并更换背景、下载。
3. 手机端卡牌入口位于报告内容末尾，不产生横向滚动。
4. 报告外框尺寸与首页、聊天、报告列表等页面保持一致。
5. 报告详情内部滚动、返回报告列表、报告列表二级进入、音频播放均不回退。
6. 键盘可以聚焦并打开卡牌预览，焦点状态清晰可见。
