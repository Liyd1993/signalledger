# EchoReport 首页、归档与声音页设计

## 目标

将当前单一对话体验扩展为可立即测试的四个界面：首页、对话、报告列表、声音陪伴；保留现有非医疗自我反思定位。

## 已确认的视觉与导航

- 默认视觉为 D「晨光拼贴」：暖粉、柔黄、薄荷绿的渐变卡片，轻微旋转和圆角拼贴，不复刻任何参考图的商标、文案或构图。
- 使用 Vue 单页状态切换，不增加 Vue Router 或第三方依赖。
- 首页必须有三个真实入口：开始对话、我的报告、声音陪伴。

## 页面与行为

### 首页

展示问候语、三个入口卡片以及简短安全说明。点击入口切换到对应页面。

### 对话页

保留图片上传、十段文字解锁报告、危机提示和固定 360px 的可滚动转录区。转录区加 `align-content: start`，避免第一轮两条消息被 CSS Grid 拉开。

### 报告页与列表

生成报告后同时将其加入浏览器 `localStorage` 的报告归档。报告列表按新到旧展示标题、生成日期和摘要；点击任意项目查看其内容。无报告时显示明确的空状态并提供开始对话入口。

### 声音陪伴页

展示三段内置、免版权的 Web Audio 合成环境声音（雨声、白噪音、缓慢呼吸提示）。用原生 `<audio controls>` 播放由浏览器生成的 WAV Blob URL；可切换曲目、播放和暂停。此版本不承诺音乐疗效，也不上传或播放受版权保护的素材。

## 数据与边界

- 对话和图片仅存在本页运行内存；报告归档存在当前浏览器的 localStorage。
- 不调用本机模型、第三方 API 或远程服务。
- 图片仍是开发模拟线索，不宣称已识别图片语义；未来腾讯云多模态接入将替换该分支。

## 验收与测试

- 首页三个入口可到达各自页面，且可返回首页。
- 首次发送一条消息时，用户和回应气泡相邻排列，不出现大段空白。
- 连续十条文本消息可创建报告；报告生成后会出现在报告列表。
- 音频页能在支持 Web Audio 的浏览器中生成并播放一段声音，且无法生成时显示可理解提示。
