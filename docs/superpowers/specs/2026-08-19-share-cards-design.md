# EchoReport 我的卡牌设计规格

## 背景

用户希望把单次反思报告转成适合分享的竖版卡牌。入口放在“我的报告”列表中的每一份报告右侧；卡牌既要有视觉记忆点，也要保持 EchoReport 非医疗、基于用户真实表达的边界。

## 目标

- 每份历史报告都能进入“生成卡牌”流程。
- 同一份内容提供三种用户批准的原创背景，用户可以自行切换。
- 卡牌内容短、具体、足够共情，并明确来自当前报告而非人格诊断。
- 卡牌底部始终包含当前网站地址；部署后无需改代码。
- 用户可下载 3:4 PNG 图片用于微信、小红书等平台分享。

## 非目标

- 不提供自由拖拽、字体编辑、颜色编辑等完整海报编辑器。
- 不生成二维码，不引入二维码或截图第三方依赖。
- 不直接复用参考图、塔罗牌名称、现成插画或带水印素材。
- 不把称号描述成医学、心理或人格结论。

## 用户流程

1. 用户进入“我的报告”。
2. 每条报告保留“查看报告”行为，并在右侧增加独立的“生成卡牌”按钮。
3. 点击后进入卡牌页，默认展示“新艺术晨光”背景。
4. 用户可在三个背景选项间切换；卡牌正文保持一致。
5. 用户点击“下载 PNG”，浏览器生成并下载 1080 × 1440 图片。
6. 用户可返回报告列表，原报告数据不被修改。

## 内容结构

卡牌内容由现有报告字段确定性生成，保证刷新后稳定：

- 顶部：`ECHO CARD` 与报告日期。
- 个人称号：从报告标题和正文中的语义线索映射为非诊断式称号，例如“边界守望者”“缓慢复原者”“真诚表达者”。无法匹配时使用“认真感受的人”。
- 共情句：优先使用报告的 `feelings`，压缩为不超过 44 个汉字的一句话；空值时使用温和的通用回退文案。
- 三个关键词：从标题、`feelings`、`nextStep` 的受控关键词表中去重选择；不足时补为“觉察 / 温柔 / 向前”。
- 页脚：`EchoReport · <当前 hostname>`；本地开发显示 `127.0.0.1`，部署后自动使用正式域名。
- 说明：`基于一次真实表达生成 · 非医疗建议`。

文案遵循三条原则：看见当下感受、减少孤立感、对自己保持善意。不得出现“你就是”“你患有”“典型人格”等定性表达。

## 三种视觉方向

三款共享同一信息层级和 3:4 构图，只更换背景、色彩和装饰语言。

1. **新艺术晨光**：薄荷、桃粉、象牙白与旧金色；原创花叶、日轮和弧形边框，不出现人物复制。
2. **金线星图**：炭黑底、哑光金线、月相与星图符号；更克制、像收藏卡而非占卜结果。
3. **虹光秘仪**：深蓝黑底、青粉虹彩、原创几何星体符号；中心留出高对比文字区域。

背景素材只包含装饰与留白，不烘焙中文文字。所有真实文案由 HTML 预览和 Canvas 导出层绘制，保证可读性及内容一致。

## 页面与交互

### 报告列表

- 报告条目不再由整块 `<button>` 独占；使用条目容器承载两个明确按钮：“查看报告”和“生成卡牌”。
- 桌面端按钮位于右侧纵向或横向排列；窄屏下保持可点击宽度并避免覆盖摘要。
- 两个按钮均具备可见焦点状态和独立的无障碍名称。

### 卡牌页

- 顶部保留“回到报告列表”。
- 主区域显示一张固定比例预览，下面提供三个带缩略图和文字名称的背景选项，不以颜色作为唯一识别方式。
- 主按钮为“下载 PNG”；导出期间显示禁用状态，完成或失败均恢复。
- 预览在 320px 宽屏不横向溢出；文字对比度正文至少 4.5:1，大字至少 3:1。
- 动效仅用于样式切换淡入，并尊重 `prefers-reduced-motion`。

## 技术方案

- Vue 状态新增 `cardReport` 和 `cardTheme`，页面类型新增 `cards`。
- 新建 `src/lib/shareCard.ts`，集中负责称号、共情句、关键词、域名和导出数据，避免把逻辑继续堆入 `App.vue`。
- 新建 `src/lib/shareCard.test.ts`，验证稳定映射、文字截断、关键词回退和域名处理。
- 使用原生 Canvas 2D API 导出 PNG；背景用 CSS/Canvas 形状与三张原创装饰图组合，不引入新 npm 依赖。
- 装饰素材放在 `public/cards/`，文件名固定为三个背景 slug。

## 验收标准

- 每条历史报告右侧均能点击“生成卡牌”，且“查看报告”仍可用。
- 三款卡牌背景可切换，文案完全相同，视觉明显不同。
- 共情句和关键词由所选报告生成，旧报告字段缺失时不会崩溃。
- 卡牌预览与下载图片都包含网站地址。
- 下载图片尺寸为 1080 × 1440，文件名包含主题和日期。
- `npm test` 与 `npm run build` 通过。
- 在 390px 与桌面宽度完成浏览器回归：列表按钮、返回、主题切换、下载无控制台错误。
