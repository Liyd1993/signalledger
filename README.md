# EchoReport

一个用于演示“10 条用户表达后可选生成对话回顾报告”的 Vue Web App。

## 运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test
npm run build
```

## 边界

这是自我反思演示，不是医疗建议、诊断、治疗或紧急服务。内容保存在当前浏览器内存中，不会上传。检测到少量高风险短语时，界面会停止常规流程，并提示用户联系可信任的人、当地紧急服务或中国心理援助热线 12356。

当前 AI 回复、图片回复和报告由明确标注的本地确定性模拟逻辑生成，便于开发和测试。图片会显示在当前对话中，但不会计入 10 条文字表达。部署时将把同一接口替换为腾讯 TokenHub 的多模态模型，并把密钥放在云函数环境变量中；接入真实模型前需要单独完成隐私与安全评审。
